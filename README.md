# unsupervised_machine_learning_customer_segmentation
This project involves grouping customers into various groups based on their income and spending behaviour.The mall dataset from kaggle was used.Unsupervised machine learning techniques used include K-Means and Hierarchical clustering.Optimal number of clusters was 5 .Both K-Means and Hierarchical clustering produced similar groupings.
